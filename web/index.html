声音来源

Windows / 浏览器系统声音 · Edge 在线多语言声音 · 安卓已安装语音引擎 · 可配置 Azure 或兼容语音 API。音色菜单按语言排列，名称显示来源。

在线来源会将当前朗读段落发送到所选语音服务；默认本地阅读不上传小说。

手机独立音色与电脑同步

可安装并切换手机自带、Google、讯飞等语音引擎及语言包。中文包是否可用取决于手机已安装的引擎。手机可直接联网使用全部 Edge 在线音色，无需电脑开机。点击一键同步可带入电脑音色列表、选中声音和语速；Windows 专用声音及电脑私有 API 来源需要电脑在线合成。

自己的在线语音服务（可选）

密钥仅保存于本机，局域网手机通过电脑调用，不接收密钥。服务可能收费，请使用自己的账户。
